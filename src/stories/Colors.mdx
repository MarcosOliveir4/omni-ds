# 🎨 Cores (Theme)

As cores do **Omni DS** foram baseadas em paletas de alta performance visual para garantir o contraste e a legibilidade nativa do conteúdo.

<br />

## Paleta de Uso (Variáveis CSS)

Sempre prefira usar as variáveis CSS nos componentes, pois elas se adaptam automaticamente aos modos Light e Dark.

<ColorPalette>

    title="Brand / Primary"
    subtitle="--color-primary"
    colors={{
      Base: 'var(--color-primary)',
    }}
  />

  <ColorItem
